> 文案调整以本文件为准。行为规范见 docs/PRODUCT.md，回复定位与首个提交

## 一、这是什么

Human LLM Gateway 是一个"由人来当大模型"的网关：调用方（比如 IDE 里的
AI 编程助手）以为自己在调用一个大模型 API，实际上请求会变成一条条
**任务**送到你手里，由**你**给出回答，网关再把你的回答伪装成大模型的
响应原路返回给调用方。

- 任务从哪来：调用方通过 API 发起请求 → 网关建任务 → 推送到你绑定的 IM。
- 你的回复去了哪：原样作为这次 API 调用的结果返回给调用方（伪流式）。
- 底账在哪：每条任务在 Web 工作台都有完整原文和状态，IM 只是快捷入口，
  任何时候都可以去 Web 端查看或回复。

## 二、第一次使用：绑定机器人

1. Web 控制台 → 连接管理 → 新建连接（企微 / 微信 iLink 等）。
2. 点击「生成绑定码」，绑定码 5 分钟内有效、一次性使用。
3. 在 IM 里把绑定码**原样发给机器人**，收到"绑定成功"即完成。
4. 绑定后只有这个 IM 账号的消息会被接受；换号需重新走一遍绑定码流程。

## 三、一条任务消息长什么样

```text
#t_97549b3f… · gpt-5.6-sol · 全文8,213字（已省略开头7,913字）
──────────────
……正文末尾300字……
（回复 /page 1 可从头翻看全文）
```

- `#t_xxxx`：任务 ID，翻页和多人任务定位都靠它。
- 模型名：调用方请求的对外 Fake Model，与你真实使用哪个模型无关。
- 全文字数与"已省略开头 N 字"：说明正文被截断了，完整原文在网关里。

## 四、为什么只发末尾 300 字

Agent 类调用（IDE 助手）的提示词前面通常是海量系统上下文，**真正的提问
在结尾**，所以默认只附末尾 300 字，先看重点。想看全文用 `/page` 翻页。

## 五、看全文：/page 翻页

- `/page 1` → 第 1 页（从正文开头起，每页 500 字）。
- `/page 2`、`/page 3`……依次往后翻。
- 回包同样以 `#任务ID` 开头，页数多时网关会自动分几条消息连发。
- 多个任务在等时，翻页也要带 ID：`#t_97549b3f… /page 2`。

## 六、提交回复（三种方式，任选其一）

1. **直接发文字**（最简单）：整段消息就是最终答案。
2. `/ans 你的答案`：和直接发文字完全等价，语义更明确，适合答案本身以
   `/`、`#` 开头容易被误认成命令时使用。
3. `/res 你的思考`（换行）`你的答案`：把思考过程和最终答案一起提交，
   调用方能看到你的 reasoning。例如：

```text
/res 先核对预算再排期
按方案 B 执行，周三前给出细化表。
```

提交规则（重要）：

- **首个有效提交生效**：哪个入口先提交成功（IM 或 Web），任务就完成。
- **提交后不可撤销、不可覆盖**：发错也无法修改，提交前请确认内容；
  答错了只能等调用方下一次请求。
- 提交成功你会收到确认；若提示"任务已结束"，说明已被 Web 端抢先回复、
  超时或取消，此时再发的内容无效。
- **工具调用不在 IM 提交**：任务里列出的 tools 是调用方声明的真实工具
  清单，仅供你了解上下文；网关从不执行任何工具，需要表达工具意图时
  直接用文字说明即可。

## 七、多条任务同时在等

- 每条任务消息开头就是 `#任务ID`，回复时把它加在最前面即可精确定位：

```text
#t_97549b3f… 直接这样答复就行
```

- 也可以直接"引用/回复"某条任务消息（平台支持的话），效果等同。
- 当前只有一个任务在等时，不加 ID 也会自动归属它。
- 每个账号同时最多 10 个活动任务，超限时调用方会收到 429，请及时清空。

## 八、注意超时：默认只等 5 分钟

- 每个任务有等待期限（API Key 上配置的人工超时）：默认 5 分钟，
  可配置范围 10 秒 ~ 30 分钟。
- 超时后任务按 Key 的 fallback 策略收尾，**晚到的回复无效**。
- 收到任务请尽快处理；来不及就去 Web 工作台处理或调大该 Key 的超时。

## 九、可选：超长任务 LLM 摘要

- 连接管理页可为每个连接开启「超长正文用 LLM 压缩」。
- 开启后，正文超过 1000 字时，网关先用你自己配置的 LLM 把全文压缩成
  摘要，再附上末尾 300 字原文一起推送。
- 摘要可能丢细节，关键任务请用 `/page` 翻原文后再答。

## 十、快捷命令速查

- `/page N`：看任务原文第 N 页（每页 500 字）
- `/ans 答案`：提交最终答案（不写思考）
- `/res 思考` + 换行 + `答案`：提交思考 + 答案
- `#任务ID` 前缀：多任务时定位某一条
- 直接发文字：等同 `/ans`
- `/help`：随时重发本教程的速查部分

## 十一、常见问题

- **回复后没有确认？** 任务可能刚被 Web 端抢先回复（首个提交获胜）、
  已超时或被取消；去 Web 工作台看任务状态。
- **内容发错了？** 提交后不可撤销；调用方下次请求时再正确作答即可。
- **消息太长被截断？** 网关会按平台限制自动分段连发，请按序阅读。
- **收不到任务？** 到连接管理页看连接健康状态；投递失败会自动重试。
- **换了微信号 / 账号？** 重新走一遍绑定码流程即可。
- **不想被打扰？** 停用连接即可；任务仍会出现在 Web 工作台，随时可回。
