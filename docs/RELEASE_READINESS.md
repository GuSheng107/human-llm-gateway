# 受邀试用验收记录

验收日期：2026-09-05。基线提交：`db7b657`；本记录随本次修复提交保存。

## 结论

当前版本可以作为**单实例、邀请码注册、小规模受邀试用版本**交给他人部署或使用。
Web 人工回复的三协议完整链路已本地验收；使用 IM、真实 LLM 或公网访问的实例，
还须完成 [DEPLOYMENT.md](DEPLOYMENT.md) 的对应现场检查。

不将本地测试等同于生产环境验收，也不承诺多 worker、多副本、高并发 SLA 或旧库迁移。
M10/M11 的已交付部分与剩余验收项见 [ROADMAP.md](ROADMAP.md)。

## 本次关闭的问题

| 问题 | 修复与证据 |
|---|---|
| 人工截止后，sweeper 会误杀正在生成的 fallback | 人工等待、转发声明和上游生成分别计时；回归覆盖已超人工截止但上游仍工作的情形 |
| I/O 超时不能约束持续输出的总时长 | 流式、非流式自动转发都增加 600 秒总预算，残留任务有独立收敛宽限 |
| 跨协议参数拒绝被包装为 500/504 | 三协议、直转/fallback、流式/非流式 12 种组合返回兼容 400，并释放名额、保留稳定错误码 |
| Chat system 内容块被字符串化 | 保持原始数组与内容块，追加身份文本块，不改写原始请求 |
| API Key 可以在列表/详情反复取回明文 | 完整 Key 仅创建响应返回；读取和更新只给前缀，新 Key 不再存可逆密文 |
| IM 工具调用一律被拒绝 | 与 Web 共用规范化、声明名称和参数结构校验；网关不执行工具 |
| 关闭后台协程后数据库线程仍在运行 | 清理与 sweeper 等待线程完成后才退出；新增测试在修复前失败、修复后通过 |
| 重启残留活动任务长期占名额 | 单实例启动和退出时取消残留任务并幂等释放名额，保留已完成结果 |
| 旧库会被启动过程自动补列 | 删除兼容补列分支；结构不匹配时只读拒绝，新库直接创建目标结构 |
| 缺少可执行备份恢复和监控入口 | 新增 SQLite 在线备份/校验/恢复 CLI 与低基数 Prometheus 指标 |
| 手机页面横向溢出、弹窗焦点留在背景 | 修复控制台与任务筛选布局，弹窗/抽屉限制 Tab 焦点并在 Esc 关闭后恢复焦点 |
| 环境说明、开发代理和进度记录不一致 | 固定 Python 3.12、声明实际 Node 范围、统一 8000 端口、增加 CI，更新双语 README 和路线图 |

## 浏览器与真实 HTTP 验收

使用临时 SQLite 文件、随机主密钥、合成管理员/普通用户及临时 API Key，后端直接托管
生产前端资源；没有读取部署凭据，没有向真实 IM 联系人发送消息或调用付费上游。
浏览器登录态由隔离测试夹具建立；验证码、首次改密与登录权限由自动化测试覆盖。

没有把浏览器静态截图当作协议成功证据。

## 备份与关闭验证

- 使用真实 WAL 数据库生成一致性备份，恢复到新路径后成功读到用户及加密数据。
- 不允许覆盖原库或已有备份；错误主密钥和损坏文件不能恢复。
- 关闭清理重复执行不会重复扣名额；已完成的任务与结果保持不变。
- 后台线程取消测试确认：数据库工作未结束时，关闭协程不会提前返回。

## 目标实例仍需验收

3. 启用的 LLM 配置验证草稿、直接转发、人工超时 fallback 及真实上游失败。
